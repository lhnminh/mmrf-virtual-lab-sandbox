Journey 1: CGS high risk vs standard risk

  1. User asks to compare survival for CGS high risk versus standard risk.
  2. Chat panel POSTs /agent/v1/prompts with the prompt and the selected cohort.
  3. Agent calls correlation_plot("overall survival", "CGS risk").
  4. The executor resolves both names and sends two filters (High risk, Standard risk) to Gen3 Analysis.
  5. Tool returns summary to the model and plot to the response: 339 vs 661 cases, p = 7.1e-60.
  6. Response JSON carries message and toolCalls; the chat panel renders the plot with <SurvivalPlot>.

Phase 2 (later): streaming, multi-turn history, Helm/EKS deployment, IAM role for Bedrock, possible move to Bedrock AgentCore. Executors stay the same.
